This is browser based speedometer that uses your device’s GPS to display your current speed. It was designed to show the street name and local speed
limit using an external API, with options for MPH and km/h. 

The project uses:

  - HTML, CSS, and JavaScript for the interface and app logic.
  - The Geolocation API to read the device’s location and speed.
  - An external road data API to request street names, speed limits, and local speed units.
  - Responsive CSS and device orientation detection to adapt the display for mobile screens.
  - Local Storage to save the selected speed unit.
  - A basic Progressive Web App

It was completed as an individual project in 2025 as part of my Mobile App Development Course at the university of Strathclyde.

Note: The external API is currently returning errors, so street names and speed limits may not appear.
